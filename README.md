# Holberton School — Web React

مشاريع الواجهة الأمامية الحديثة: TypeScript ثم React.

| المجلد | المشروع |
| --- | --- |
| `TypeScript` | الأنواع الأساسية، الواجهات والكلاسات، DOM، الأنواع المتقدمة، namespaces، الملفات المحيطة، و nominal typing |

كل مجلد مهمة (`task_0` … `task_5`) مستقل بذاته: له `package.json` و
`tsconfig.json` خاص به، وتُشغّلينه بـ `npm install` ثم `npm run build`.
